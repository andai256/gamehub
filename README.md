# GameHub

A collection of 26 retro arcade and puzzle mini-games with profiles, scores,
a shop, achievements and stats. Runs fully offline: no network permission,
no ads, no tracking.

The game itself is a single HTML file (`app/src/main/assets/index.html`) shown
in an Android WebView.

## Build

Open the project in Android Studio and run it, or from a terminal with Gradle:

    gradle :app:assembleRelease
